# Customer Segmentation using K-Means Clustering

## 📌 Overview
This project implements the K-Means Clustering algorithm to segment customers based on their Annual Income and Spending Score.

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## 📂 Dataset
Mall_Customers.csv

## 📖 Concepts Covered
- Unsupervised Learning
- K-Means Clustering
- Elbow Method
- WCSS
- Customer Segmentation

## 📊 Output
- Elbow Method graph
- Customer cluster visualization
